# 모바일 청첩장 PRD
## Wedding RSVP 0130

### Concept
**하나보다 나은 둘**

---

## 1. 개요

카카오톡 링크 기반 모바일 웹 청첩장.  
결혼식 정보를 전달하는 동시에, 두 사람의 관계성과 분위기를 스크롤 경험으로 표현한다.

전형적인 웨딩 템플릿보다:

- 인간적인 거리감  
- 손으로 만든 듯한 감성  
- 둘이 연결되는 리듬

에 집중한다.

---

## 2. 목표

- 모바일 환경에서 빠르게 정보 전달  
- 감정 중심 스크롤 경험 설계  
- “예쁜 청첩장”보다 “둘다운 청첩장” 구현  
- 최소 인터랙션으로 몰입감 제공

---

## 3. 사용자

카카오톡 링크로 진입하는:

- 친구  
- 가족  
- 지인

모바일에서 짧게 확인하는 상황을 전제로 한다.

---

## 4. 정보 구조

```plaintext
Hero
→ Intro (커플 사진 + 초대 메시지)
→ Date (날짜 + 달력 카드)
→ Location (지도 + 교통 안내)
→ Menu (코스 요리 미리보기)
→ Gallery (메인 사진 + 썸네일)
→ Account (계좌 accordion)
→ Footer
```

> RSVP는 MVP에서 제외. 별도 채널(카카오톡 등)로 대체.

---

## 5. 섹션 정의

### Intro
- 짧은 카피 + 심볼 그래픽  
- 감정 톤 진입 역할

### Hero
- 이름 / 날짜 / 스크롤 유도  
- 스크롤 기반 reveal 인터랙션  
- “둘이 연결되는 감각” 표현

### 두 사람 소개
- 관계의 분위기 전달  
- 자연스러운 사진 중심 구성

### 초대 메시지
- 손글씨 무드  
- 짧고 담백한 문장 구성

### 웨딩 정보
- 날짜 / 시간 / 장소  
- 빠른 정보 확인 우선

### 갤러리
- 세로 스크롤 기반  
- 비정형 레이아웃 허용  
- 확대 모달 지원

### 위치
- 지도 / 주소 / 교통  
- 카카오맵 · 네이버맵 연결

### RSVP
- 이름 / 참석 여부 / 동행 인원  
- 최소 입력 구조

### 계좌
- 신랑측 / 신부측 구분  
- 펼치기 / 복사 기능

### Ending
- 감사 메시지  
- 잔잔한 fade-out 마무리

## 7. 비주얼 컨셉

### Core Value

- 둘이라서 더 재밌는 관계  
- 완벽하지 않아도 자연스러운 분위기  
- 손으로 만든 듯한 따뜻한 느낌  

### Design Keywords

- 단순한 도형 중심 그래픽  
- 흑백 기반 + 종이 질감  
- 포스터 / 독립출판물 같은 무드  

---

## 8. 인터랙션 원칙

### 지향
- 느린 reveal  
- 연결되는 motion  
- 종이 같은 움직임  
- 미세한 흔들림

### 지양
- 과한 parallax  
- 무거운 애니메이션  
- 화려한 웨딩 템플릿

---

## 9. 기술 방향

### Stack

- HTML  
- CSS (`tokens.css` + `style.css`)  
- Vanilla JS (`main.js`)
- Vercel (자동 배포)

### 파일 구조

```
index.html
tokens.css     ← 디자인 토큰 (색상, 타이포, 간격)
style.css      ← 섹션별 레이아웃 & 컴포넌트
main.js        ← 인터랙션 (reveal, envelope, gallery, account)
assets/        ← 이미지, SVG 아이콘
```

### 구현 원칙

- Mobile-first  
- 디자이너 수정 가능한 구조 (tokens.css에서 토큰 관리)
- semantic HTML 우선  
- 최소 라이브러리 사용
