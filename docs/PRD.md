# 모바일 청첩장 PRD

## OS 템플릿 스타일 기반 인터랙티브 웨딩

---

# 1. 프로젝트 개요

## 프로젝트명

Wedding RSVP 0130

## 프로젝트 정의

모바일 환경에 최적화된 인터랙티브 웨딩 초대 경험을 제작한다.  
단순 정보 전달 중심의 청첩장이 아니라, 감정 몰입과 분위기 전달을 중심으로 한 모바일 기반 마이크로사이트 형태로 구성한다.

사용자는 카카오톡 링크를 통해 진입하며, 세로 스크롤 기반의 시네마틱 흐름 안에서 결혼식 정보와 감정적 메시지를 자연스럽게 경험한다.

---

# 2. 프로젝트 목표

## UX 목표

- “청첩장을 읽는다”보다 “짧은 웨딩 필름을 경험한다”에 가까운 경험 제공
- 모바일 환경에서 몰입감 있는 감성 인터랙션 구현
- 카카오톡 공유 시 첫 인상(OG 이미지/첫 화면)을 극대화
- 최소한의 조작으로 자연스럽게 정보 확인 가능하도록 설계
- 신랑/신부의 분위기와 무드를 브랜드처럼 전달

---

# 3. 핵심 사용자

## Primary User

- 카카오톡 링크를 통해 모바일로 청첩장에 진입하는 가족, 친구, 지인
- 모바일 웹 사용에 익숙한 20~30대 사용자
- 짧고 감성적인 콘텐츠 소비에 익숙한 사용자

## 사용자 특징

- 긴 텍스트보다 비주얼 중심 경험 선호
- 세로 스크롤 기반 탐색에 익숙함
- 인스타그램 릴스/브랜딩 사이트 스타일에 익숙함
- 모바일 환경에서 빠른 정보 확인 기대

---

# 4. UX 방향성

## 핵심 경험 키워드

- Cinematic
- Emotional
- Minimal
- Soft Motion
- Immersive Scroll

## UX 원칙

### 1. 모바일 퍼스트

모든 경험은 모바일 세로 화면 기준으로 설계한다.

### 2. 감정 흐름 중심

정보를 나열하기보다 감정 흐름에 따라 콘텐츠를 배치한다.

### 3. 인터랙션 절제

과도한 애니메이션보다 부드러운 전환과 분위기 유지에 집중한다.

### 4. 한 화면 한 메시지

각 섹션은 하나의 감정 또는 메시지에 집중한다.

---

# 5. 정보 구조

```plaintext
카카오톡 링크 진입
↓

Gallery
↓

```

# 6. 주요 섹션 정의

## 6-1. Hero Section

### 목적

첫 진입 시 감정적 임팩트 제공

### 구성 요소

- 풀스크린 이미지 또는 영상
- 신랑/신부 이름
- 웨딩 날짜
- 짧은 메시지
- Scroll Indicator

### 인터랙션

- Fade-in 텍스트
- 부드러운 패럴랙스
- Slow zoom animation

### 비주얼 방향

OS 템플릿 스타일 기반의 미니멀하고 영화적인 톤

---

## 6-2. Opening Message

### 목적

초대 메시지 전달

### 구성 요소

- 짧은 초대 문구
- 여백 중심 레이아웃
- 타이포 강조

### 인터랙션

- Scroll reveal
- Text fade transition

---

## 6-3. Couple Introduction

### 목적

신랑/신부 소개

### 구성 요소

- 프로필 이미지
- 이름
- 간단한 소개 문구
- 가족 정보

### 인터랙션

- 이미지 reveal
- 카드 fade-up

---

## 6-4. Wedding Information

### 목적

예식 정보 전달

### 구성 요소

- 날짜
- 시간
- 장소
- 연락처
- 계좌 정보

### UX 정책

- 정보 우선순위를 명확하게 구성
- 긴 텍스트 최소화
- 버튼 기반 인터랙션 활용

---

## 6-5. Gallery

### 목적

웨딩 분위기 전달

### 구성 요소

- 세로형 이미지 갤러리
- 필름 감성 레이아웃
- 큰 이미지 중심 구성

### 인터랙션

- Scroll reveal
- Masonry 느낌의 레이아웃
- 확대 모달

### 성능 정책

- Lazy loading 적용
- 이미지 압축 필수

---

## 6-6. Location / Map

### 목적

하객의 이동 편의 제공

### 구성 요소

- 지도
- 주소
- 교통 정보
- 길찾기 버튼

### 기능

- 카카오맵 연동
- 네이버맵 연동
- 클립보드 주소 복사

---

## 6-7. RSVP

### 목적

참석 여부 수집

### 구성 요소

- 참석 여부 선택
- 이름 입력
- 동행 인원
- 식사 여부

### 기능

- 간단 폼 제출
- 모바일 최적화 입력 UX

---

## 6-8. Ending Section

### 목적

감정 마무리

### 구성 요소

- 감사 메시지
- Ending visual
- 배경 음악 종료

### 인터랙션

- Slow fade-out
- 마지막 장면 연출

---
