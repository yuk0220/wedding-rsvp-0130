# 모바일 청첩장 PRD
**Wedding RSVP 0130**

---

## 1. 개요

카카오톡 링크로 진입하는 모바일 웹 청첩장.  
세로 스크롤 기반으로 결혼식 정보를 자연스럽게 전달한다.

---

## 2. 목표

- 최소한의 조작으로 정보를 바로 확인할 수 있도록
- 히어로 인터랙션(편지봉투 오픈)으로 첫 인상 강조
- 인사말은 손글씨 무드로, 인간적인 온도 유지

---

## 3. 사용자

카카오톡 링크를 통해 진입하는 가족·친구·지인.  
모바일 환경에서 짧게 확인하는 상황을 전제로 한다.

---

## 4. 정보 구조

```
히어로 → 요약 안내 → 인사말 → 일자 → 위치 → 사진 → 계좌 → 끝맺음
```

---

## 5. 섹션 정의

### 히어로
- 편지봉투 이미지, 신랑/신부 이름, 결혼식 일자, Scroll Indicator
- 스크롤 시 봉투 오픈 → 사진 reveal
- 타이틀: 타이핑 또는 손글씨 작성 애니메이션

### 요약 안내
- 날짜·시간·장소 한눈에 파악
- 스크롤 없이 읽히는 구조

### 인사말
- 초대 문구, 신랑/신부 이름, 양가 부모님 성함
- 손글씨체 폰트, fade-up 등장

### 일자
- 날짜·시간 강조 표시

### 위치
- 지도, 장소명·주소, 교통 정보
- 카카오맵·네이버맵 연동, 주소 복사

### 사진
- 세로형 갤러리, 확대 모달
- Lazy loading, 이미지 압축

### 계좌
- 신랑·신부 측 계좌, 은행명·예금주
- 펼치기/접기, 복사 버튼

### 끝맺음
- 감사 메시지, fade-out

---

## 6. 제외 기능

| 기능 | 이유 |
|------|------|
| 배경음 | 무음 환경 대응 불가, 갑작스러운 재생 우려 |
| 화환주기 | 광고성으로 느껴질 수 있음 |
| 방명록 | 작성 부담, 적은 수 노출 시 역효과 |
