# wedding-rsvp-0130
인터랙션 기반 모바일 청첩장

카카오톡 링크로 진입하는 모바일 웹 청첩장.
세로 스크롤 기반.

**배포**: https://wedding-rsvp-0130.vercel.app/

## Sections
- Hero: 편지봉투 (closed → open → reveal)
- Intro: 커플 사진 + 초대 메시지
- Date: 달력 카드 + 날짜 정보
- Location: 지도 + 교통 안내
- Menu: 코스 요리 미리보기
- Gallery: 메인 사진 + 썸네일 리스트
- Account: 신랑/신부측 계좌 
- Footer: 마무리 메시지

## Stack
- HTML
- CSS (style.css + tokens.css)
- Vanilla JS (main.js)
- Vercel (자동 배포)
